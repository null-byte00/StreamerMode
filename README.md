# StreamerMode

Скрывает выбранные окна из записи экрана, OBS и любого захвата — при этом они остаются видны тебе.

![Windows](https://img.shields.io/badge/Windows-10%2F11-blue) ![.NET](https://img.shields.io/badge/.NET-8-purple)

## Как работает

- **Список окон** — видишь все открытые окна, выбираешь режим для каждого:
  - `—` — не трогаем
  - `По режиму` — скрывается когда включён стример-режим
  - `Всегда` — скрыто постоянно, без всяких биндов
- **Стример-режим** — глобальный тогл (кнопка в окне, трей или хоткей `Ctrl+Alt+H`): одним нажатием прячет все окна «по режиму»
- **Правила сохраняются** — закрыл/переоткрыл Discord → он снова сам скроется
- **«Весь процесс»** — скрывать любое окно программы, независимо от заголовка

## Технически

Использует `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)` — официальный API Windows (10 2004+). Окно невидимо для Display Capture / Game Capture / Game Bar / OBS, но на экране остаётся обычным.

## Запуск

Single-file exe, ничего ставить не надо. Windows 10 2004+ / 11.
